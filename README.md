# 가계부

브라우저에서 바로 쓰는 단일 파일 가계부입니다. 설치나 서버 없이 `가계부.html` 파일 하나만 열면 동작합니다.

## 기능

- 수입 / 지출 내역 입력 (날짜, 금액, 분류, 메모)
- 수입 · 지출 · 잔액 자동 집계
- 월별 / 유형별 필터링
- 내역 삭제
- `localStorage` 기반 자동 저장 — 브라우저를 닫아도 내역이 유지됩니다

## 사용법

`가계부.html` 파일을 브라우저(Chrome, Edge 등)로 열면 됩니다.

## 참고

내역은 서버로 전송되지 않고 사용한 브라우저에만 저장됩니다. 따라서 다른 기기나 다른 브라우저에서는 내역이 보이지 않으며, 브라우저 데이터를 삭제하면 내역도 함께 지워집니다.

## 기술

HTML / CSS / 바닐라 JavaScript. 외부 라이브러리 의존성 없음.
